No-Explicit-QA Deep Sets ENSEMBLE Ablation

Date: 2026-06-03

Purpose

This ablation tests whether the newest QA-pruned Deep Sets ENSEMBLE benefits from explicit QA features inside the final candidate-set weight model.

It keeps the same QA-pruned candidate pool and the same object-vote settings as the current best strict run, but removes the explicit QA feature columns from the Deep Sets weight model:

  • qa_score
  • qa_rank_in_image
  • ranker_cluster_qa_rank

Because relative candidate-set features are generated from the configured base features, removing those three columns also removes their candidate-set rank/centered/gap derivatives. The no-explicit-QA model has 212 numeric features plus 26 one-hot categorical features, for input dimension 238. The full model has 224 numeric features plus 26 one-hot categorical features, for input dimension 250.

Important limitation: this is not a fully no-QA pipeline. The candidate pool is still QA-pruned, and pairwise_cluster_score may still encode upstream QA-related information. This isolates explicit QA evidence inside the final Deep Sets ENSEMBLE.

Command

.venv/bin/python scripts/qa_pruned_ensemble/run_pruned_candidate_set_weight.py \
  --model-type deep_sets \
  --candidate-run clipped_score_boundary_floor075_thr050 \
  --run-label-suffix trainonly_ltv_boundary_floor075_e080_no_explicit_qa \
  --train-split train \
  --deep-sets-epochs 80 \
  --weight-transform raw_cluster_softmax \
  --weight-temperature 1.0 \
  --vote-threshold 0.48 \
  --boundary-support-column local_image_support_score \
  --boundary-floor 0.75 \
  --boundary-iterations 1 \
  --exclude-explicit-qa-features \
  --overwrite

Interpretation

The explicit QA features are not carrying the final ENSEMBLE. Removing them loses only 0.000697 mean IoU overall. This supports the interpretation from the real case study: QA is a noisy, sometimes useful signal, but the stronger parts of the newest ENSEMBLE are the candidate-set context, source/geometry/support evidence, and Deep Sets weighting.

This does not mean QA is useless in the whole pipeline. The pool is still QA-pruned, and some upstream ranking features may still contain QA influence. What this ablation says is narrower and cleaner: explicit QA columns inside the final Deep Sets weight model provide only a small marginal gain.
