Current Approach: Quality-Aware Dynamic Candidate Selection

Purpose

This document summarizes the current approach in enough detail for another agent to rewrite it into a dissertation or book-style chapter. It focuses on the conceptual method, how it differs from the original QA/ENSEMBLE idea, what the current implementation does, and which results should be treated as the current state of evidence.

Short Summary

The current method is best described as:

quality-aware dynamic candidate selection for silver-truth segmentation

It uses multiple candidate segmentation masks for the same object, synchronizes them into local object clusters, scores each candidate using QA-like and contextual evidence, selects the most reliable candidates, and reconstructs a final segmentation mask.

The method evolved from the original QA-gated ENSEMBLE idea. The original idea was to predict segmentation quality, filter low-quality candidates, and feed the remaining candidates into an ENSEMBLE model. The current evidence suggests that the most robust decision is not a hard QA threshold or a direct neural mask-generating ENSEMBLE. It is a local candidate-ranking problem.

Dissertation Framing

The dissertation proposal is about improving segmentation using ensemble methods with quality assurance. It highlights a limitation of Cell Tracking Challenge silver-truth generation: candidate methods are filtered mostly at the model or dataset level, but individual object instances can vary strongly in quality.

The current method addresses exactly that limitation:

  • it operates at object-instance level;
  • it uses quality-related evidence to select or prune candidates;
  • it works with multiple segmentation sources;
  • it can be used before or instead of fusion;
  • it targets improved silver-truth masks.

The safest dissertation wording is:

The original QA-gated ENSEMBLE architecture was reformulated as quality-aware dynamic candidate selection. Instead of relying on one global QA threshold or a fixed-input neural mask generator, the system ranks candidate masks inside synchronized object clusters using QA, source reliability, temporal context, geometry, and image-support features.

This is still aligned with QA-driven dynamic ensemble pruning. It should not be presented as unrelated feature engineering.

Reporting Taxonomy

Use this terminology consistently:

  • FUSION is not ENSEMBLE.
  • FUSION is not our method.
  • ENSEMBLE is our method.
  • fusion_only_* rows are external fusion baselines.
  • ensemble_only and ensemble_qa_* rows are our ENSEMBLE methods.
  • qa_only_* rows are QA-selection ablations.
  • full_pipeline_* rows are deployable pipeline rows that apply our QA/filtering logic to a fusion proposal set.
  • The current soft-hybrid / ranker rows are deployable quality-aware candidate selection rows, not strict QA/ENSEMBLE rows.

Use separate tables for:

  1. strict QA/ENSEMBLE methods;
  2. deployable quality-aware candidate selection;
  3. external fusion baselines;
  4. external competitors and silver truth.

Method Data Flow

The current pipeline can be described as:

paper-ready candidate table
-> candidate feature extraction
-> optional candidate/pairwise ranker
-> soft-hybrid scoring
-> local conflict resolution and candidate selection
-> reconstruction of selected candidates into segmentation masks
-> validation-based strategy selection
-> reporting against fusion, competitors, and silver truth

The important unit is the synchronized object cluster: several candidate masks from different sources may correspond to the same real cell. The task is to decide which candidate or subset of candidates should represent that cell.

Feature Families

The current approach combines several feature families.

Feature family Purpose
QA score Estimate candidate mask reliability.
Fusion/support evidence Capture local agreement among candidate sources.
Source identity / source prior Model source reliability differences.
Temporal support Capture frame-to-frame plausibility.
Morphology / geometry Capture shape, size, position, border contact, and crop geometry.
Crop image features Use raw image evidence inside stacked square crops.
Rectangular image features Use tighter object-local image/mask statistics.
Full-image features Measure object evidence in true image coordinates.
Boundary/noise features Capture contrast-to-noise, boundary gradients, holes, eccentricity.
Local image support score Cluster-relative image evidence used as a soft-hybrid support term.

Interpretation:

  • It wins against fusion-only on three of five datasets.

  • It is still below the best external competitor average.
  • The support-mode improvement is real but very small: about +0.000165 mean IoU over the current selected full-image baseline.

Known Failure Modes

The current method is not yet a clean replacement for fusion.

Main regressions:

Dataset Issue
BF-C2DL-HSC Small regression versus fusion-only; likely strategy selection or conservative tie-breaking issue.
Fluo-C2DL-MSC Large regression versus fusion-only and best competitor; highest-priority failure case.

MSC is the main blocker because:

  • current method loses to fusion-only by about -0.0221 IoU;
  • current method loses to the best competitor by about -0.0505 IoU;
  • image features helped MSC substantially in earlier probes;
  • full-boundary/local-support features helped one MSC fold slightly;
  • the remaining gap may be reconstruction/fusion-related rather than purely candidate-ranking-related.

Important diagnostic question:

Is fusion better on MSC because it selects better object candidates, or because averaging/voting boundaries produces a better final mask than direct candidate selection?

That question motivates the next major experiment: run fusion after QA/ranker pruning.

Why This Is Not Just Old-School Feature Engineering

The current approach uses engineered features, but those features are serving a scientific purpose. They expose which signals matter before building a higher capacity neural system.

The earlier neural ENSEMBLE approach may have struggled because:

  • the input crops were too large and background-heavy;
  • the true problem is a variable-size set problem;
  • a fixed stacked-mask U-Net is not naturally source-aware or permutation-invariant;
  • the objective should often be ranking/pruning, not full mask generation;
  • there may be too little cross-dataset data for a high-capacity model;
  • temporal context was not central enough in the neural input;
  • source identity and source reliability were not represented explicitly enough.

The current feature/ranker system should therefore be treated as a blueprint for the next neural model.

Neural Direction To Preserve

The likely next neural direction is:

object-local candidate encoder
+ source identity / source embedding
+ temporal candidate context
+ permutation-aware set aggregation
+ pairwise or listwise ranking objective
+ optional fusion after neural QA pruning

This is more promising than a generic stacked-mask U-Net because it matches the actual decision problem:

  • candidates are variable in number;
  • source order should not matter;
  • local candidate comparison is more stable than global QA regression;
  • the final output can still be produced by classical fusion after neural pruning.

This neural model should come after the QA-pruned fusion and ablation work, because those experiments will reveal which signals are worth learning.

Chapter-Level Narrative

A dissertation/book chapter can use this structure:

  1. Problem. CTC silver-truth generation relies on model-level filtering and fusion, but object-level candidate quality varies.
  2. Original hypothesis. QA can identify unreliable masks and improve ENSEMBLE/fusion.
  3. Observed limitation. Hard QA thresholds and first neural ENSEMBLE variants were brittle under dataset/fold transfer.
  4. Reformulation. Treat the task as quality-aware dynamic candidate selection inside synchronized object clusters.
  5. Method. Extract QA, source, temporal, geometry, and image-support features; train a pairwise/source-aware ranker; select candidates; reconstruct masks.
  6. Results. Strong improvement over strict QA/ENSEMBLE baselines and mean improvement over fusion-only, but still dataset-specific failures.
  7. Analysis. MSC and HSC regressions show why direct candidate selection is not enough; QA-pruned fusion is the next decisive test.
  8. Future architecture. Use the engineered ranker as a guide for a neural candidate-ranking model rather than returning to a generic mask generator.
